# NovaStudio — Digital Agency Landing Page

Landing page premium "Dark Luxury" pour agence digitale, construite avec Next.js 15, TypeScript, Tailwind, React Three Fiber, GSAP et Framer Motion.

## Étape actuelle : Navbar + Hero 3D

- ✅ Navbar transparente avec effet glass, blur, liens animés, menu mobile
- ✅ Hero avec objet 3D holographique interactif (rotation, suit la souris, particules Sparkles)
- ✅ Smooth scroll (Lenis) branché sur GSAP ScrollTrigger
- ✅ Curseur personnalisé (dot + ring magnétique)
- ✅ Typo Space Grotesk (titres) / Inter (texte)
- ✅ Fond aurora gradient + grille + blobs animés

## Installation

```bash
npm install
npm run dev
```

Ouvre http://localhost:3000

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS
- React Three Fiber + Drei + Three.js
- GSAP + ScrollTrigger
- Framer Motion
- Lenis (smooth scroll)
- Lucide Icons
